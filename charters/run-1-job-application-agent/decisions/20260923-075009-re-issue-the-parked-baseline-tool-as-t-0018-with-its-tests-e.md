## Decision
No new goals, no new milestone - M1-M3 still map one-to-one onto G1-G3. Add one task, T-0018, which re-issues T-0011's tool with depends_on: [] so it cannot inherit a parked gate, and with the six required tests spelled out instead of left to the worker: the design is explicitly declared not up for redesign, since two reviewers already called it correct and both failures were test-coverage failures.
